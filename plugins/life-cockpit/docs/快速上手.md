# 快速上手 · 20 分钟跑起来

这份文档只回答一个问题：**一个从没见过这个插件的人，怎么在自己的笔记库里，不碰后端、不碰服务器、不填任何 API key，把第一个番茄跑起来、记上第一笔积分、看到自己的目标树。**

先把最重要的一句话放在最前面：

> **这个插件本来就不依赖后端。** Convex 后端是同步层，不是运行时依赖——后端整个挂掉，番茄计时、遮罩、强制干扰、往笔记库落盘全都照跑。所以照着本文档跑起来的不是阉割版，是完整的单机体验。

两个前提，先确认你符合：

- **桌面端**。本插件 `isDesktopOnly: true`，**不支持移动端**；要求 Obsidian **1.6.6 或更高**。
- 一个普通的 Obsidian 笔记库（vault）。没有的话，装好 Obsidian 随手建一个空的就行。

文档里每一条命令名、设置项名都按 [`使用手册.md`](使用手册.md) 核对过；截图位置用占位符标出，装到那一步时对照自己屏幕上的样子即可。

---

## 第 1 步 · 装上它（约 5 分钟）

插件本体就是三个文件：

1. 打开仓库的 [`dist/life-cockpit/`](../../../dist/life-cockpit/) 目录，拿到这三个文件：
   - `main.js`
   - `manifest.json`
   - `styles.css`
2. 在你的笔记库里建文件夹 `.obsidian/plugins/life-cockpit/`，把三个文件放进去。
3. 重启 Obsidian，打开 设置 → 第三方插件，启用 **Life Cockpit 人生驾驶舱**。

<!-- 截图：第三方插件列表里的 Life Cockpit 人生驾驶舱 -->

> 认版本的小窍门：`manifest.json` 里 `version` 至少是 **0.19.0**——首次运行引导和中性默认路径都是这一版才有的。

**想自己从源码构建**也可以（需要 Node）：

```bash
cd plugins/life-cockpit
npm ci
npm test          # 纯逻辑回归测试，应当全绿
npm run build     # tsc --noEmit + esbuild → main.js
cd ../..
node scripts/update-life-cockpit-package.mjs   # 把三件套同步进 dist/life-cockpit/
```

构建完回到上面第 2 小步。

## 第 2 步 · 第一次打开：三个问题怎么选（约 1 分钟）

启用之后第一次打开，会弹出一屏引导：

> ## 欢迎使用人生驾驶舱
> 三个问题，问完就能用。不想现在定就跳过——之后随时能在设置里改。

一屏三问（不是一步步的向导），新手推荐这么选：

| 问题 | 推荐 | 怎么做 |
| --- | --- | --- |
| 数据落在哪个文件夹 | **不动** | 留默认的 `LifeCockpit/` 就好。番茄流水、积分账本、目标树、候选区、复盘日记、复盘素材、错题本都在它下面 |
| 节奏 | **思考优先** | 下拉里点一下换成「思考优先」（注意：下拉默认停在「加速实践」）。25 分钟工作 + 5 分钟休息，要想清楚再动手选它；一头扎进去干就选加速实践 45+10 |
| 界面档位 | **不动** | 保持「新手 · 开箱即用」。大部分选项灰着只读，能改的只有字号和各层总开关——这是故意的 |

然后按 **「就这样，开始用」**。

<!-- 截图：首次运行引导的一屏三问 -->

两件小事提前说清，免得以为是 bug：

- **跳过、ESC、点窗外，都算做过选择**，引导这辈子只在真的第一次弹。想让引导重新弹出来：删掉 `.obsidian/plugins/life-cockpit/data.json` 里的 `onboardingDone` 这一项即可。
- 选错了也无所谓——每一问之后随时能在设置里改。

## 第 3 步 · 跑通第一个番茄（1 分钟按下，25 分钟走完）

打开驾驶舱面板，三条路任选：

- 点左侧栏的**计时器图标**（三个 ribbon 图标之一）；
- 点状态栏上的计时区；
- `Ctrl/Cmd + P` 打开命令面板，跑 **`打开人生驾驶舱`**。

<!-- 截图：驾驶舱面板全貌 -->

面板中央有一颗大按钮 **「开工」**，点它。倒计时开始走。

**25+5 是怎么回事**：当前模式下一段工作 25 分钟（「思考优先」档），走完自动进 5 分钟休息，如此往复。工作多久、休息多久由模式决定，不用你管。

三条规矩现在说清楚，后面就不会惊讶：

1. **休息的表不等人**：工作段一到点，休息的钟立刻自己开始走，不需要你按任何东西（休息段会有全屏休息页，Esc 随时退出，退出不停表）。
2. **开工永远是手动的**：休息结束之后，下一段工作**停着等你来按**——面板写着「等你开工」、按钮变回高亮的「开工」。这是设计，不是坏了：「自动开始下一段」那个开关在这个插件里被整个删掉了。
3. **结束本段 ≠ 今天收工**：手动按「结束本段」，休息照常开始、催促照常继续。真要今天到此为止，走命令面板的 **`今天收工（停掉今天的催促）`**。

<!-- 截图：停着等人的工作段（等你开工） -->

**跑满一段会发生什么**：当日专注分钟数 +25，状态栏常驻显示今天已专注多少；同时自动记一笔积分「完成一个番茄」（默认 2 分，见下一步）。注意**跑满才算**——手动结束的那一段不计分。

不想坐等 25 分钟验证完整流程的话，命令面板里有 **`演练一次强制干扰（20 秒）`**，20 秒过一遍收工前会发生的全套动静。

## 第 4 步 · 记第一笔积分（约 3 分钟）

番茄之外的事，手工记账。两条入口：

- 命令面板跑 **`记一笔积分`**；
- 或者驾驶舱面板积分区的 **「＋记一笔」** 按钮。

弹窗里四个字段：

1. **方向**：入账 · 完成任务 / 出账 · 享乐消耗；
2. **任务**：下拉选预设任务（分值和事由自动带出）；没有合适的选「临时任务」自己填——临时任务**不用先登记**；
3. **推进的目标**：可以空着（目标树建好之后再挂，见下一步）；
4. 分值与事由，可改。

最小动作：方向保持「入账」，任务选「完成一个番茄」，确定。

<!-- 截图：记一笔积分弹窗 -->

**账落在哪里**：`LifeCockpit/积分账本/2026-08.md`，一个月一份 Markdown，在 Obsidian 里直接能翻能搜：

```markdown
## 流水

| 时间 | 账本日 | 方向 | 分值 | 余额 | 事由 | 任务 | 来源 | 关联 | 状态 | ID |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 2026-08-09 09:25 | 2026-08-09 | + | 2 | 2 | 完成番茄：完成一个番茄 · 写 PRD | pomodoro | 番茄 | work-1-… | 有效 | … |
```

记错的不用慌：命令面板 **`撤销最近一笔积分`** 会写一笔方向相反的撤销单，原笔留在账上——**不做静默删除**。

**任务与分值在哪儿维护**：不在设置页，在 vault 的一篇笔记里。命令面板跑一次 **`写出积分任务表`**，它会写出 `LifeCockpit/积分账本/积分任务表.md`（默认表取自日记模板六维与早晚流程），然后直接改。一张可直接抄的最小样例：

```markdown
| ID | 名称 | 方向 | 分值 | 分类 | 启用 |
| --- | --- | --- | --- | --- | --- |
| pomodoro | 完成一个番茄 | 入账 | 2 | 诚 | 是 |
| video | 刷视频 30 分钟 | 出账 | 12 | 享乐 | 是 |
```

两条规矩：`ID` 用过就别改（账本按它指回来）；改完文件跑一次 **`重读积分账本`** 生效。

## 第 5 步 · 建第一棵目标树（约 5 分钟）

目标树从宇宙级到日内一共六层：

> 宇宙级 → 人生级 → 大阶段 / 五年计划 → 【年度】OKR → KPI → 日内目标

**六层不用一次建满。** 命令面板跑 **`写出目标树`**，它会写出 `LifeCockpit/目标树.md`，里面是一份六层骨架（每层一句占位的措辞，直接改成你自己的话就行）。

只想先要两层？把骨架正文换成这样也能用：

```markdown
## 树

- [ ] 宇宙级目标：把日子过成自己认账的样子 [进度:: 0%] ^g-1
    - [ ] 日内目标：今天专注 4 个番茄 [进度:: 0%] [层级:: 日内] ^g-2
```

三个细节：

- **缩进决定层级**（顶格是宇宙级，往里缩一层降一级）；跳级的时候要在子行写明 `[层级:: 日内]` 这样的标记，不然会被当成相邻层。
- 行尾的 `^g-1` 是节点号；手写时忘了写也不要紧，读盘时自动补号。
- `[进度:: n%]` 是算出来的，改它没有意义——勾掉 `[x]` 一个日内目标，能看到上层跟着往前动（这就是回灌）。

改完文件跑一次 **`重读目标树`**。

**把番茄挂上去**：驾驶舱面板顶部有「推进的目标」下拉（目标树面板里点节点旁的 ○，或跑命令 **`把番茄挂到某个目标上`** 也一样）。能挂的是**日内目标和 KPI**——再往上太高，挂上去没有意义。挂上之后，这个番茄记在哪条目标名下、这一支今天投了几个番茄，面板上都看得见。

## 第 6 步 · 推动器最小配置（约 2 分钟）

推动器把这些提醒推到 Obsidian 窗口之外。好消息：**它的默认值就已经是最小配置，你大概率什么都不用动**：

| 项 | 默认值 | 要凭据吗 |
| --- | --- | --- |
| 启用推动器 | 开 | 不要 |
| 系统通知渠道 | **开** | **不要任何凭据** |
| 免打扰时段 | 22:00 – 05:00 | — |
| 每日配额 | 24 条 | — |
| 飞书 / 通用 webhook | 关 | 要（本轮不展开，可选，见 [`可选模块.md`](可选模块.md)） |

看一眼它们的位置：设置 → 左栏 Life Cockpit 人生驾驶舱 → 标签页 **「推送 · 推荐」** → 「主动推送」一节。新手档下大部分项灰着只读，这是有意的；想改免打扰时段或配额，把设置页最上面的档位切到 **「专家 · 全部可改」**，改完切回新手（切回去不会还原你改过的值）。

<!-- 截图：推送 · 推荐标签页的主动推送一节 -->

验证通不通：命令面板跑 **`试推一条（看看渠道通不通）`**，你的系统应该弹出一条通知。

嫌吵的正确顺序是：先调「最低分级」，再调每日配额，最后才是整个关掉。

## 附：不想点鼠标？一份可以直接放的配置

正常路径下**没有任何必须手写的配置**——第 2 步的三问答完，`data.json` 就齐了。
想赶在第一次启动前把它放好，就用下面这份。

### 就用这一份：`data.beginner.json`

仓库里有一份 [`data.beginner.json`](data.beginner.json)，它**不是编出来的样例**——
它就是仓库主人**日常高频在用**的那份 `data.json`，脱敏之后放进来的：
凭据、地址、他的私人路径全部清空，十个路径改成中性的 `LifeCockpit/`，档位调回新手。

**Obsidian 关着的时候，把它复制到 `.obsidian/plugins/life-cockpit/data.json` 就能用。**

它的价值在于那**一百多项被真实调过的参数**——是「用了很久之后的选择」，不是默认值。
下面这张表把值得你单独看一眼的几项挑出来，**每一项都标了照抄还是自己调**：

| 项 | 值 | 照抄 / 自己调 | 说明 |
| --- | --- | --- | --- |
| `settingsVersion` | 2 | **照抄** | 当前配置版本，别改 |
| `onboardingDone` | true | **照抄** | 它就是「不弹引导」的开关；想再看一次引导就删掉这个键 |
| 十个 `LifeCockpit/…` 路径 | `LifeCockpit/…` | **照抄**（想换根目录再调） | 数据落点，中性默认根。整组搬家最省事的办法是删掉 `onboardingDone` 让引导重弹 |
| `activeMode` | thinking-first | **照抄起步** | 思考优先 25+5，就是引导里推荐的那个答案 |
| `dailyFocusTargetMinutes` / `dailyWindowHours` | 560 / 14 | **按自己调** | 一天 14 小时窗口、目标专注 560 分钟。**这是标尺不是 KPI**，按你自己的作息改 |
| `dayRolloverHour` | 4 | **按自己调** | 一天从**凌晨 4 点**算起，熬夜写的东西才不会被记成第二天。不熬夜的人改回 0 |
| `pomodoroAlternateEnabled` / `Ratio` | true / 0.5 | **按自己调** | 间歇节奏真的在用：单数轮基准时长，双数轮减半，长休息不缩 |
| `sessionRestoreEnabled` / `sessionGraceMinutes` | true / 5 | **按自己调** | 跨重启接得回来，但离开超过 5 分钟那段**一秒不算专注** |
| `zenCoverWork` | false | **按自己调** | 禅定遮罩**不盖工作段**——工作时要看得见别的窗口 |
| `uiFontScale` | 1.1 | **按自己调** | 界面整体放大一成 |
| `phaseMapping` | weekday | **按自己调** | 五行节律按星期几映射 |
| 所有 `*ApiKey` / `*Token` / `*Url` / `*Webhook` / `aiProfiles[].apiKey` | `""` | **保持空着** | 已经清空了。要用哪个模块，再去设置里填哪个——**别把填好的这份提交到任何仓库** |

没列出来的那一百多项**照抄就行**：它们要么是默认值，要么是不影响你上手的细节，
以后在设置里遇到再调。

### 只想要最小的那一份

嫌上面那份太长、想从一张白纸开始，这三行也够：

```json
{
  "settingsVersion": 2,
  "onboardingDone": true,
  "activeMode": "thinking-first"
}
```

- 其余键**全部不用写**：插件加载时对缺失字段按默认值补齐，不会因为「少键」而丢弃整份配置；
- 这份的效果 = 引导里推荐的三个答案（默认文件夹 + 思考优先 + 新手档）。代价是引导不会再弹——想再看一次就删掉 `onboardingDone`。
- 换来的代价：上面那一百多项调好的参数你一项都拿不到，全部走默认值。

## 卡住了？

- **目标树下拉是空的 / 提示「任务表还没建」**：多半撞上了冷启动的索引竞态，跑一次 `重读目标树` 或 `重读积分账本` 即可（详见[手册 · 冷启动](使用手册.md)）。
- **想让引导重新弹**：删掉 `data.json` 里的 `onboardingDone`。
- **想把数据整体搬到别的文件夹**：让引导重新弹一次（删掉 `data.json` 里的 `onboardingDone`），第一问改的就是整组落点；只想动某一处，去设置对应小节改那一项目录，改完重读一遍账本与目标树。
- 更完整的说明（每一种落盘格式、每一条行为边界）：[`使用手册.md`](使用手册.md)。
